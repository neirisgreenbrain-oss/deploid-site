Автоматизация браузера

Помощник для работы с объявлениями

Заполнять одинаковые поля вручную утомительно. Я сделал настольную программу, которая переносит данные объявления в форму, сверяет важные поля и сохраняет ход работы.

Прикладная разработка

Проблема

Одни и те же поля заполняются вручную, легко ошибиться в цене или адресе.

Что я сделал

Собрал окно управления с шаблоном, параметрами и списком адресов. Подключил Chrome через расширение, добавил тестовое заполнение без публикации и сохранение обработанных записей.

Как это устроено

Сверка перед отправкой

Цена, название и адрес читаются со страницы и сравниваются с заданными. Несовпадение требует исправления и повторной проверки.

Оператор остаётся в процессе

На затруднении программа показывает вопрос. Можно повторить шаг, выполнить его вручную, пропустить запись или остановить работу.

Продолжение после паузы

Прогресс сохраняется отдельно от шаблона. При следующем запуске уже обработанные записи можно пропустить.

Технические подробности+

Python и настольный интерфейс Tkinter, расширение Chrome и локальный канал связи. Есть отдельные модули управления вводом для Windows и macOS. Для проверки формы предусмотрен локальный макет. Работа с живым сайтом зависит от его интерфейса и условий использования.

  • Python
  • Chrome Extension
  • Tkinter
  • Windows / macOS
