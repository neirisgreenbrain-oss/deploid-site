Внутреннее веб-приложение

Рабочее пространство для проектов с ИИ

При работе с ИИ полезно видеть не только переписку, но и то, что происходит с проектом. Для этого я собрал веб-интерфейс с файлами, историей и терминалом.

Собственный рабочий проект

Проблема

Диалог, файлы и команды находятся в разных окнах; после перерыва теряется контекст.

Что я сделал

В одном интерфейсе можно открыть проект, найти разговор, посмотреть изменения и продолжить работу. Действия, которым нужно разрешение, проходят через подтверждение.

Почему сделано так

Сессия на сервере

Переподключение браузера не создаёт новую терминальную сессию. Сервер сохраняет сессию и буфер вывода.

Изменения рядом

Файлы, поиск по истории и изменения Git собраны в рабочем интерфейсе проекта.

Подтверждение действий

Для операций, требующих разрешения, предусмотрен отдельный шаг подтверждения в интерфейсе.

Технические подробности+

События передаются через WebSocket. Терминальная сессия работает на сервере, с буфером вывода для переподключения. В интерфейс встроены просмотр изменений Git, поиск по истории и управление разрешениями.
